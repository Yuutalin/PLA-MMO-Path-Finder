PLA MMO Path Finder - Pokemon image resources

Images are optional. RNG calculation works without this folder or any images.

Automatic cache:
  static/pokemon/cache/

User-provided images (takes priority over cache):
  static/pokemon/custom/

Expected file names follow the local RNG engine format, for example:
  c_712.png       regular Bergmite
  c_712s.png      shiny Bergmite
  c_712-1.png     alternate form (form id 1)
  c_712-1s.png    shiny alternate form

The application checks the image files locally. It does not bundle third-party Pokemon artwork.
The optional downloader retrieves images from PokeAPI's public sprite repository / API at runtime.
