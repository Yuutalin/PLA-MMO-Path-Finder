# PLA MMO Path Finder v0.7.3

## 本次更新

- 计算完成后，宝可梦信息、属性、路径概要和详细步骤采用轻量渐进显示，减少结果区域突然出现的突兀感。
- 结果数量、Seed／群体摘要、研究等级与闪耀护符摘要、计算状态消息增加轻量过渡。
- 空结果状态与结果卡片使用一致的进入过渡；重复计算时可重新触发动画。
- 动画使用透明度与位移，不使用高斯模糊，并遵守系统「减少动态效果」设置。
- 保持 Seed 读取、路径计算、结果排序和 RNG 算法不变。
- 完善项目说明、上游代码与图片来源说明、使用教程和 GitHub 截图占位图。

## 使用方式

### 直接运行源码

1. 下载并解压源码 ZIP。
2. Windows 10/11 安装 Python 3.10 或更高版本。
3. 双击项目根目录的 `start.bat`。
4. 首次启动按提示准备依赖和本地计算引擎。

### 构建 Windows 版本

在 Windows 上运行 `build_tools\\build.bat`，选择便携版、安装版或两者同时构建。源码仓库不包含预编译 EXE。
